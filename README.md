# 🎮 ChaosArena — PvPvE Roguelite Action

> Сессионный многопользовательский экшен-рогалик для двух игроков.  
> Вдохновлён Soul Knight. Разрабатывается на Godot Engine 4.6 (C# / .NET 8).

---

## 📖 О проекте

**ChaosArena** — это сессионная игра для двух игроков, в которой каждый раунд состоит из трёх фаз:

1. **PvE-фарм** — каждый игрок зачищает свою процедурно сгенерированную арену от волн монстров, зарабатывая валюту.
2. **Магазин + Рулетка Хаоса** — между раундами игроки тратят валюту на оружие и улучшения, а также влияют на глобальное случайное событие.
3. **PvP-дуэль** — игроки встречаются на общей арене. Победа засчитывается до 3 побед в матче.

Ключевая механика — **асимметрия информации и саботаж**: ты не знаешь что купил соперник, но можешь потратить деньги чтобы усложнить его PvE-фазу.

## 🎯 Игровые механики

### Игровой цикл
```
Лобби → PvE-фарм (60 сек) → Магазин → Рулетка Хаоса → PvP-дуэль → [повтор до 3 побед]
```

### Двухслотовая система оружия
- **Слот 0** — оружие для PvE. Наносит больше урона мобам, слабее в дуэли.
- **Слот 1** — оружие для PvP. Сильнее против игрока, слабее против мобов.
- Переключение клавишами `1` и `2`.

### Рулетка Хаоса
Глобальное событие между раундами. Случайный бафф или дебафф применяется к одному или обоим игрокам. Игроки могут тратить валюту чтобы:
- Повлиять на результат в свою пользу.
- Назначить плохой эффект сопернику.

### Система Саботажа
Во время PvE-фазы игрок может потратить валюту чтобы:
- Выключить свет на арене соперника.
- Призвать усиленного моба на арену соперника.
- Заморозить управление соперника на несколько секунд.

### Система Камбэка
Проигравший дуэль получает уникальный бонус перед следующим раундом (усиленное оружие, дополнительное HP, скидку в магазине). Защита от snowballing.

### Экономика
- Стартовый баланс: **100 золота**.
- Награда за убийство моба: **5–15 золота** (случайно).
- Валюта тратится в магазине, на саботаж и ставки в рулетке.

## 🏗️ Архитектура проекта

### Технологии
| Компонент | Технология |
|-----------|-----------|
| Движок | Godot Engine 4.6.3 (.NET / mono) |
| Язык | C# / .NET 8.0 |
| Сеть | P2P (Host-Client) через ENet + Godot RPC |
| IDE | JetBrains Rider |
| ОС разработки | Linux Mint |

### Структура папок
```
res://
├── autoload/           # Синглтоны (автозагрузка)
│   ├── EventBus.cs     # Глобальная шина событий (сигналы)
│   ├── GameManager.cs  # State Machine фаз игры
│   └── EconomyManager.cs # Валюта и транзакции
│
├── entities/
│   ├── player/
│   │   ├── PlayerBase.cs      # Абстрактный базовый класс игрока
│   │   ├── LocalPlayer.cs     # Локальный игрок (ввод, анимация)
│   │   └── RemotePlayer.cs    # Сетевой игрок (интерполяция)
│   ├── weapons/
│   │   ├── WeaponBase.cs      # Абстрактный класс оружия
│   │   ├── Bullet.cs          # Снаряд
│   │   └── RangedWeapon.cs    # Дальнобойное оружие
│   └── enemies/
│       ├── EnemyBase.cs       # Абстрактный класс врага
│       └── BasicEnemy.cs      # Базовый враг (преследование, knockback)
│
├── scenes/
│   └── MapGenerator.cs        # Процедурная генерация подземелья (BSP)
│
├── systems/
│   ├── EnemySpawner.cs        # Волновой спавнер врагов
│   ├── SabotageSystem.cs      # Система саботажа (TODO)
│   ├── ChaosWheel.cs          # Рулетка хаоса (TODO)
│   └── ComebackSystem.cs      # Система камбэка (TODO)
│
├── ui/
│   ├── HUD.cs / HUD.tscn      # Полоска HP и счётчик золота
│   └── ShopUI.cs              # Магазин между раундами (TODO)
│
└── assets/
    ├── ui/                    # Текстуры интерфейса
    ├── Tilemap/               # Тайлсет подземелья (Kenney Tiny Dungeon)
    └── Tiles/                 # Отдельные тайлы
```

### Ключевые паттерны
- **Composition over Inheritance** — оружие собирается из компонентов (`ProjectileComponent`, `MeleeComponent`).
- **EventBus** — системы не знают друг о друге, общаются через глобальные сигналы.
- **Authority-based Networking** — каждый игрок — authority своего персонажа, хост — authority мира и экономики.

## 🌐 Сетевая архитектура

### Топология
```
Хост (Player 0)  ←──ENet P2P──→  Клиент (Player 1)
      │                                   │
   Authority:                          Authority:
   - Фазы игры                        - Своя позиция
   - Экономика                        - Своя стрельба
   - Спавн врагов
   - Валидация саботажа
```

### RPC-вызовы
| Метод | Направление | Описание |
|-------|-------------|----------|
| `RpcSyncPhase` | Хост → Все | Синхронизация фазы игры |
| `RpcSyncState` | Owner → Все | Позиция и HP игрока |
| `RpcRequestSabotage` | Клиент → Хост | Запрос саботажа |
| `RpcSyncEconomy` | Хост → Все | Обновление баланса |

## 🚀 Запуск проекта

### Требования
- Godot Engine 4.6.3 (.NET версия) — [скачать](https://godotengine.org/download)
- .NET SDK 8.0 — [скачать](https://dotnet.microsoft.com/download)
- JetBrains Rider (рекомендуется) или VS Code с расширением C#

### Установка
```bash
git clone https://github.com/jota2069/chaos-arena.git
cd chaos-arena
```

Открой папку в Godot через **Project → Import**.

### Первый запуск
1. Открой проект в Godot
2. **Project → Tools → C# → Build** (первая сборка)
3. Нажми **F5** для запуска

### Управление
| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| ЛКМ | Стрельба |
| 1 | Слот оружия PvE |
| 2 | Слот оружия PvP |

## 🤝 Для разработчиков

### Добавление нового оружия
1. Создай класс наследующий `WeaponBase` в `entities/weapons/`
2. Переопредели `Fire(Vector2 origin, Vector2 direction, GamePhase phase)`
3. Настрой `PvEMultiplier` и `PvPMultiplier` для баланса
4. Создай сцену `.tscn` и добавь спрайт
5. Зарегистрируй в магазине (после его реализации)

### Добавление нового врага
1. Создай класс наследующий `EnemyBase` в `entities/enemies/`
2. Переопредели `OnReady()` и `_PhysicsProcess()`
3. Создай сцену `.tscn` с `CollisionShape2D`, `Sprite2D`, `Hitbox (Area2D)`
4. Установи `CollisionLayer = 1`, у `Hitbox` — `CollisionLayer = 4`

### Добавление нового события в EventBus
```csharp
// В EventBus.cs добавь:
[Signal] public delegate void MyNewEventEventHandler(int param1, float param2);

// Эмитировать:
_eventBus.EmitSignal(EventBus.SignalName.MyNewEvent, value1, value2);

// Подписаться:
_eventBus.MyNewEvent += OnMyNewEvent;
```

### Коллизионные слои
| Слой | Назначение |
|------|-----------|
| 1 | Игроки, враги (тела) |
| 2 | Пули |
| 4 | Хитбоксы врагов (Area2D) |
