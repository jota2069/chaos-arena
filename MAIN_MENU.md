## 🔄 Auto-Updater

### Как работает
```
1. Игра запускается
2. HTTPRequest → GitHub Releases API
3. Сравнивает текущую версию с последней
4. Есть новая? → показывает диалог "Доступно обновление X.X.X"
5. Игрок нажимает "Обновить" → скачивает новый .zip
6. Распаковывает → заменяет файлы → перезапускается
```

### GitHub API запрос
```
GET https://api.github.com/repos/jota2069/chaos-arena/releases/latest
```

### Диалог обновления
```
┌─────────────────────────────┐
│   🔄 ДОСТУПНО ОБНОВЛЕНИЕ    │
│                             │
│   Версия 1.2.0              │
│   Что нового:               │
│   - Новые мобы              │
│   - Исправлены баги         │
│                             │
│  [ ✅ ОБНОВИТЬ ]            │
│  [ ❌ ПОЗЖЕ ]               │
└─────────────────────────────┘
```

### Версия в проекте
```csharp
// В GameManager или отдельном классе
public const string GameVersion = "1.0.0";
```

## 🎨 Визуальный стиль меню

**Цвета:**
- Фон: тёмно-фиолетовый #1A0A2E
- Кнопки: тёмный камень с золотой рамкой
- Текст активный: золотой #FFD700
- Текст неактивный: серый #888888
- Акцент: фиолетовый #8B00FF

**Анимации:**
- Логотип: плавно появляется при загрузке (Tween alpha 0→1)
- Кнопки: появляются по очереди снизу вверх
- При наведении: кнопка светится золотым
- Фон: лёгкая анимация частиц (искры летят вверх)

**Шрифт:** Press Start 2P везде
